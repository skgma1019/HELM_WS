실행: 저장소 루트에서 `python -m pytest -q`.

Windows의 Python 3.11 가상환경에서는 `.\.venv\Scripts\python.exe -m pytest -q`.

프로젝트 실행 의존성과 pytest, httpx가 설치된 Python 환경을 사용한다.
테스트는 임시 DB·지도·스냅샷 경로와 테스트 토큰을 사용하며 실제 `data/`는 변경하지 않는다.

severity 경계값과 설정 반영, 이벤트 저장·중복·필터·확인 처리, REST/WS 연동,
좌표계·구역 판정, mock 로봇의 페이로드와 오프라인 버퍼 재전송을 검증한다.
mock 버퍼 테스트는 소켓 대역을 사용하며 실제 네트워크 단절 시연은 포함하지 않는다.

Node.js가 있으면 프론트 필터·집계·확인 처리·모달·마커 회귀 검증도 실행한다.
없으면 해당 테스트 1개를 skip한다. DOM/canvas 대역을 사용하므로 실제 브라우저의
시각적 레이아웃 검증을 대신하지 않는다. 별도 npm 의존성은 필요 없다.
